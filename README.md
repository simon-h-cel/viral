# VIRAL ALLURE — Prompt Generator

## Deploy sou Vercel

### Step 1 — Telechaje GitHub Desktop
https://desktop.github.com

### Step 2 — Kreye repo GitHub
1. Ale sou github.com → New Repository
2. Non: `viral-allure-generator`
3. Public → Create

### Step 3 — Upload fichye yo
Kopye tout fichye sa yo nan repo a:
- index.html
- api/generate.js
- vercel.json
- package.json

### Step 4 — Deploy sou Vercel
1. Ale sou vercel.com → Sign up ak GitHub
2. "Add New Project" → chwazi repo `viral-allure-generator`
3. Klike "Deploy" (pa chanje anyen)

### Step 5 — Ajoute Grok API Key
1. Nan Vercel dashboard → Settings → Environment Variables
2. Ajoute:
   - Name: `GROK_API_KEY`
   - Value: `xai-VOTRE_CLÉ_ICI`
3. Klike Save → Redeploy

### Step 6 — Jwenn URL ou a
Format: `https://viral-allure-generator.vercel.app`

## Jwenn Grok API Key
1. Ale sou: https://console.x.ai
2. Kreye kont → API Keys → Create Key
3. Kopye kle a → mete nan Vercel
